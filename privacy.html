Privacy Policy

vpstime backup only uses the Google Drive scope drive.file. It can only create, read and delete files that it uploaded itself. It cannot see or access any other files in your Google Drive.

No personal data is collected, sold or shared with any third party. OAuth tokens are stored only on the owner's own server and are used only to upload and manage backup files.

You can revoke access at any time at https://myaccount.google.com/permissions.

Contact: the owner of the GitHub organization vpstime.
